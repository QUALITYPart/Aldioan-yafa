# ديوان آل قفة

موقع الديوان — تم فصل الصور عن الكود لتحسين سرعة التحميل.

## هيكلة المشروع
```
index.html      ← الصفحة الرئيسية (كانت 4 ميجا، صارت أقل من 200 كيلوبايت)
images/         ← جميع صور الموقع (16 صورة)
```

## طريقة الرفع على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. ارفع محتويات هذا المجلد (index.html ومجلد images) في جذر الـ Repository مباشرة (بدون مجلد إضافي حولها).
3. من إعدادات الـ Repository → Pages → اختر الفرع (main) والمجلد (root).
4. الموقع سيصبح متاحًا على: `https://username.github.io/repo-name/`

## ملاحظة
تم حذف صورة واحدة كانت مكررة وغير مستخدمة فعليًا في الكود (كانت تُستبدل فورًا بصورة أخرى بنفس الاسم)، مما وفّر حجمًا إضافيًا دون أي تأثير على شكل الموقع.
